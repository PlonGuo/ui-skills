# 原理与参数

引擎把一组点平滑移动到图形轮廓附近，再叠加轻微运动和交互变化。

可以把它想成一群人举着灯：几何公式给出站位，运动规则让灯轻微漂浮，悬停时切换颜色并产生一次扩散。没有站位和运动规则，单独复制一个 Canvas 标签不会得到效果。

## 独立实现流程

1. **点位**：将容器划成网格，对每个格子的点位加入随机偏移。打乱点位顺序，让背景点和图形点都覆盖整个容器。
2. **图形**：用三次贝塞尔曲线（由起点、终点和两个控制点定义的平滑曲线）生成一个大括号，再镜像得到另一个。立方体由投影到平面的线段生成，不需要纹理图片。
3. **插值**：线性插值是按比例混合两个位置。图形点混合背景位置和轮廓位置，再按时间平滑接近目标，避免瞬间跳动。
4. **运动**：正弦函数提供轻微漂浮；距离函数让靠近指针的点向外移动。进入或离开时添加一次随时间衰减的扩散。
5. **绘制**：Canvas 2D 是浏览器二维画布接口。每帧清空画布，使用圆点、颜色和透明度绘制粒子，不使用 WebGL、Shader 或第三方动画库。
6. **生命周期**：IntersectionObserver 观察画布是否进入视口；ResizeObserver 观察容器尺寸。不可见时取消绘制任务，卸载时移除画布、监听器和观察器。

实现来源以所附 `particle-engine.js` 为准。参考网站只提供视觉方向，不提供本引擎的代码或素材。

## 参数

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `shape` | braces | braces / cube |
| `imageUrl` | 未设置 | 用户有权使用的自定义图形 |
| `density` | 50 | 相对粒子数量，受 300–1800 个点的范围限制 |
| `particlesScale` | 0.6 | 点的半径倍率 |
| `cameraZoom` | 8.8 | 图形大小的反向倍率；保留命名方便调整，本引擎没有三维相机 |
| `pixelRatio` | 设备像素比，最高 2 | 画布清晰度与成本 |
| `colors` | 灰、红、蓝 | 背景与图形的配色 |
| `trigger` | 画布容器 | 悬停和键盘聚焦的触发区域 |

自定义图片先缩放到 240×240，再提取非白色、非透明的像素作为目标点。选居中、边缘清楚的深色图形；细字和复杂纹理的辨识度较差。远端图片需要允许跨域读取，优先使用项目内资源。

独立页在 1024px 及以下改为纵向排列，使用系统字体。接入已有项目时，字体和排版由项目决定。

自查：图形是否可辨认？悬停后颜色能否恢复？隐藏时是否仍在绘制？手机有无横向溢出？用户要求减少动态效果时是否保持静态？
