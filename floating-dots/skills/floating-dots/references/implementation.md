# 参数与排障

光圈控制哪些短线更亮、更大并向外偏移，像一束移动的灯光照亮散布的亮点。它需要连续、平滑的运动；每帧重新随机位置会让画面闪烁。

## 保留的实现

`floating-dots-engine.js` 用泊松采样（让随机点之间保持最小距离的方法）生成不规则点位，并预先绘制短线图集，再复用图集绘制每帧。`motion.js` 计算光圈跟随、半径呼吸和粒子位移；`noise-field.js` 提供连续噪声（邻近位置产生平滑关联数值的方法），让短线自然流动。

三个模块是一个完整运行单元。默认画面无图片依赖；独立页面的字体只影响正文，不影响粒子。

## 支持参数

以下参数可在挂载时传入，也可通过 `setOptions()` 部分更新。数值必须有限，未知字段会被忽略；除背景色和种子外，表中数值会限制在支持范围内。

| 参数 | 默认值 | 支持范围与影响 |
| --- | --- | --- |
| `background` | `#000000` | Canvas 背景色，使用合法 CSS 颜色字符串 |
| `density` | `220` | `100–290`，越大点越密，会重建点位 |
| `particlesScale` | `0.65` | `0.1–3`，短线整体大小 |
| `ringWidth` | `0.15` | `0.001–0.3`，宽光圈区域 |
| `ringWidth2` | `0.05` | `0.001–0.2`，亮边宽度 |
| `ringDisplacement` | `0.23` | `0–1`，亮边向外位移强度 |
| `followSpeed` | 约 `1.212` | `0.01–12`，指针跟随速度，越高越快 |
| `idleSpeed` | 约 `0.603` | `0.01–12`，自主漂浮跟随速度 |
| `pixelRatioCap` | `2` | `1–3`，设备像素比上限，越高绘制成本越高 |
| `maxParticles` | `16000` | `1–30000`，粒子数量上限，取整 |
| `seed` | `20261009` | 随机种子，控制可重复点位与自主漂浮路径 |

光圈宽度和位移采用内部归一化坐标，不是像素；当前没有公开的固定光圈半径、颜色数组或纹理图片选项。不要传入不存在的 `colors`、`imageUrl`、`wheelTarget` 或 `interactive` 参数。

优先在独立预览的 `/?tune=1` 中调参，用 Copy current parameters 复制参数到目标组件。独立模板保留 demo 的标题、按钮、本地字体和 CSS 多色光标；接入已有项目时采用宿主内容和样式。

## 排障与验证

| 现象 | 检查与处理 |
| --- | --- |
| 导入失败 | 三个模块是否一起复制并保持相对路径，是否通过 HTTP 和项目构建工具加载 |
| 背景空白或极小 | 专用容器是否有宽高，是否被不透明内容层完全遮住 |
| 标题或按钮消失 | 是否把正文放进了会被 `replaceChildren` 替换的背景容器 |
| 鼠标经过按钮不跟随 | 是否错误地把监听迁到画布，保留原引擎的 `window` 监听 |
| 动画静止 | 检查减少动画设置、标签页是否后台、容器是否离屏及 `stats().running` |
| 手机上不跟手指 | 这是默认行为；验证粒子显示和正常滚动，明确需要触摸交互时再修改输入方式 |
| 帧率不足 | 先降低 `density`、`maxParticles` 或 `pixelRatioCap`；保留图集缓存，避免每个点重新画路径 |

在生成目录执行 `pnpm check` 和 `pnpm test`，不需要安装依赖。`pnpm install --frozen-lockfile` 安装浏览器测试依赖后执行 `pnpm test:browser`，需要系统 Google Chrome；可用 `PORT` 和 `SCREENSHOT_DIR` 改端口与截图目录。此命令会自行启动并清理预览服务器。

浏览器检查覆盖实际像素、连续帧、指针跟随和离开、内容点击、手机/平板/高清屏与减少动画时静态调参。Node 测试覆盖运动、参数和生命周期，但无法代替浏览器绘制验证。

维护打包资源时，将三个模块与确认的 demo 同步，在原项目运行 `pnpm test:skill` 检查独立输出、资源完整性和拒绝覆盖，再对生成的独立页面运行浏览器检查。
