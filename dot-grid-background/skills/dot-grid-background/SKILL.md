# Dot grid background

这个 skill 用独立的 Canvas 2D 点阵实现安静的深色背景。点位固定在规则网格上，指针靠近时只改变局部颜色、透明度和极小的半径，不移动点，也不产生漂浮或排斥力。

## 工作方式

先阅读目标页面的布局、背景容器尺寸和包管理器，再选择输出方式：

- 独立预览页：读取 [模板说明](references/template.md)，运行 `scripts/materialize.py --destination <dir> --mode standalone`。
- 接入已有项目：读取 [接入说明](references/integration.md)，运行 `scripts/materialize.py --destination <dir> --mode runtime`，然后在目标组件中挂载模块。

不要复制整站样式覆盖宿主项目。背景画布应放在内容下面，内容本身保持可访问和可交互。

## 视觉约束

- 默认背景色为 `#191b1f`。
- 默认点阵间距为 `29px`，点半径约 `1.25px`，适合桌面工作区的稀疏密度。
- 指针响应半径约 `170px`，使用平滑衰减；响应只改变颜色、透明度和最多约 `0.18px` 的半径。
- 默认点位必须稳定。不要加入随机漂移、噪声、弹簧、排斥或吸引算法，除非用户明确要求另一个效果。
- 画布覆盖容器，使用设备像素比上限 `2` 保持清晰度和成本平衡。
- 背景画布设置 `aria-hidden="true"`；页面正文、按钮和链接由宿主项目负责可访问性。

## 生命周期

在容器尺寸已确定后初始化。监听尺寸变化和指针离开，组件卸载时移除监听器并取消待处理的 `requestAnimationFrame`。页面隐藏时停止重绘，重新可见时补画一帧。

用户启用 `prefers-reduced-motion: reduce` 时，保留静态点阵；不要强制持续动画。

## 验证

至少检查：初始画布覆盖容器、点阵间距稳定、鼠标附近颜色变化、鼠标离开后恢复、窗口缩放、页面隐藏/恢复、窄屏无横向溢出，以及宿主内容仍位于背景之上。构建通过不能代替实际浏览器检查。

这个 skill 只提供独立实现，不包含第三方站点的脚本、图片、字体或品牌资源。
