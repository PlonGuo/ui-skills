# 参数与排障

引擎把每张照片的三维位置投影到屏幕，再按远近顺序绘制。

它像镜头前的一条旋转楼梯：前方照片大、后方照片小；每个角到镜头的距离不同，矩形在画面里会成为梯形。只旋转一张平面图会丢失这种变化，用一次平面贴图填梯形又会漏黑边。

## 已确认的默认参数

这些值共同形成宽屏斜向构图，不是所有项目都必须采用的通用常数。先替换图片，只有需求要求时才调整构图。

| 参数 | 默认值 | 调整影响 |
| --- | --- | --- |
| `helix.radius` | `1` | 轨道半径 |
| `helix.pitch` | `1.986` | 每转一圈的高度差 |
| `helix.turns` | `1.82` | 轨道圈数 |
| `helix.cardsPerTurn` | `15 / 1.82` | 与圈数相乘后取整，默认 15 张 |
| `cardWidth` / `cardAspect` | `0.531` / `1.378` | 世界坐标中的宽度、宽高比 |
| `cornerRadius` | `0.075` | 圆角比例 |
| `camera.fovDeg` / `camera.distance` | `15.08` / `4.8` | 垂直视角与镜头距离；一起决定大小和透视 |
| `camera.centreX` / `camera.centreY` | `0.491` / `0.445` | 构图中心相对容器的位置 |
| `axisRollDeg` / `axisPitchDeg` | `2.4` / `-1.2` | 轨道整体朝向 |
| `cameraFacing` / `cardTilt` | `0.4` / `0.196` | 卡片朝向镜头的程度、随轨道变化的倾斜 |
| `startAngleDeg` | `149.7` | 初始照片位置 |
| `driftDegPerSec` | `7` | 松开手势后的慢速角速度 |
| `wheelGain` / `maxSpin` / `spinDecay` | `0.12` / `360` / `4.5` | 滚轮增益、速度上限、惯性衰减 |
| `farBrightness` / `endFade` | `0.48` / `0.12` | 背景亮度、轨道两端渐隐范围 |

`camera.fovDeg` 是镜头的垂直可视角度。画布的设备像素比，即实际像素与布局像素的比例，最多使用 `2`。窄屏通过画面宽度限制投影尺度，避免照片放大到屏幕外。

## 三个不能拆开的关系

1. **滚动和速度**：`impulse = deltaY * wheelGain`，再限制上限并指数衰减。浏览器以行或页报告的滚轮距离先换算成像素。向下滚动加速；向上滚动先减速，冲量足够时才反转。不要为修复方向同时反转自动播放。
2. **高度和角度**：将照片高度限制到一个轨道周期内，再从这个高度求角度。分别对高度、角度取模，会在非整数圈轨道上产生换轨。使用均匀步长，首尾间距也保持一个步长。
3. **轮廓和贴图**：四个角分别投影，裁出圆角四边形；图片分成 `6 × 4` 个网格，每格两个三角形后映射。小幅重叠消除分片抗锯齿缝，外轮廓仍由同一个裁剪路径决定。不要退回单次仿射变换，即只能旋转、缩放和错切的平面变换。

近远卡片按深度排序；卡片经过侧面时，朝向镜头的偏转逐渐收回，避免法线翻面带来方向突变。法线是垂直于卡片表面的方向，用于判断哪一面朝向镜头。

## 根据症状定位

| 症状 | 先检查 | 修复方向 |
| --- | --- | --- |
| 上下滚动与预期相反 | `onWheel` 的冲量符号 | 按确认方向修改一处符号，同步方向测试 |
| 中间很空，只有小照片 | 镜头视角、距离、画面中心 | 从默认相机恢复，逐项调整 |
| 梯形边缘漏黑 | 是否被改成单次 `drawImage` 平面填充 | 保留分片投影，并用纯色纹理检查边缘 |
| 一轮后跳位或间距异常 | 角度与高度是否分别循环 | 从同一循环高度推导角度 |
| 改图片参数后没变化 | 是否只调用了 `setOptions` | 传入新图片列表重新挂载 |
| 长页面无法滚动 | window 的 wheel 监听 | 按接入说明限制到目标容器 |
| 页面空白或残留深色块 | 容器尺寸、图片请求与解码 | 检查实际图片加载，不只检查 canvas 标签 |

## 验证范围

模板的 `pnpm test` 检查初始四张前景卡片的分布、透视收敛、远近尺寸变化、均匀间距、循环回到原位、方向映射和卸载。`pnpm test:browser` 额外检查真实解码、透视边缘、像素变化、滚轮惯性、手机/平板与减少动画。

浏览器检查依赖系统 Google Chrome。若目标环境没有 Chrome，沿用项目可用浏览器验证并报告差异；不要把未执行的浏览器检查记为通过。

## 自检

- 一次完整循环后，同一张照片是否回到相同位置？
- 大卡片是否形成左上到右下的斜线，近远两层是否反向横移？
- 是否保持向下滚动加速，同时让自动慢速播放方向不变？
